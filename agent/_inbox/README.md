# _inbox/ — transient drop zone

Drop anything here (a downloaded doc, a pasted note, a screenshot). It is **transient**:
`aidevme-wiki-process-inbox` classifies each item and routes it — a source moves to the matching `raw/`
subfolder (or becomes a capture), structured knowledge becomes a `wiki/`/`work/` stub.

Do not treat `_inbox/` as storage. It should be empty after each processing run. This folder is not
`wiki/` or `work/`, so its contents are exempt from the frontmatter invariant until routed.
