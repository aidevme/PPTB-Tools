# Footer

The line at the bottom of the tool crediting the projects it's compatible with: Scott Durow's
[dataverse-ify](https://github.com/scottdurow/dataverse-ify) runtime and
[dataverse-gen](https://github.com/scottdurow/dataverse-gen) CLI (both MIT). It also reminds users to review
the preview before committing generated files.

Source: [`src/components/Footer.tsx`](https://github.com/aidevme/PPTB-Tools/blob/main/tools/dataverse-early-bound-typescript-generator/src/components/Footer.tsx)
