# SKILL.md template for recorded skills

<!-- cspell:ignore jsonc -->

The skeleton every skill generated by aidevme-skill-recorder follows. Copy it, fill the `{{…}}` parts, and delete the
guidance in *italics*. Keep the file short (under about 300 lines): move tables, payload samples and long scripts to
`references/` and `scripts/` and link them.

## Rules for the frontmatter

- `name`: kebab-case, equal to the folder name, at most 64 characters, describing the task (`export-managed-solution`).
  Never "claude" or "anthropic". Follow the repository's naming rule where it has one.
- `description`: at most 1024 characters. One sentence of what it does, a **Use when** list of the phrases a user would
  type, and a **Does NOT** clause naming the nearby tasks it doesn't do. This text alone decides whether the skill
  fires.
- Only the [Agent Skills specification](https://agentskills.io/specification) fields at the top level: `name`,
  `description`, and optionally `license`, `allowed-tools`, `compatibility` and `metadata`; Claude Code also reads
  `argument-hint`. Repository conventions go under `metadata`.

## Checklist before showing the preview

- [ ] No secret, identifier or customer value from the evidence anywhere (frontmatter, body, examples, references).
- [ ] Every destructive or irreversible step has a confirmation step that names target and scope.
- [ ] Every command, flag and endpoint was checked against its documentation or `--help`.
- [ ] UI steps that remain are marked **Fragile (UI)**.
- [ ] The procedure ends with **Verify**, and Verify names a concrete check.
- [ ] The description has a Use when list and a Does NOT clause.
